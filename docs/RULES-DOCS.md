> **D44 — khối nào trích tệp nào.** Chạy ở gốc repo; đừng chép kết quả vào đây:
>
> ```bash
> n=0
> while IFS= read -r l; do
>   [ -z "$l" ] && continue
>   n=$((n+1))
>   f=$(printf '%s' "$l" | sed -E 's/^[^:]+:[0-9]+:Nguồn mẫu: `([^`]+)`.*/\1/')
>   s=$(printf '%s' "$l" | sed -E 's/.*, chuỗi `([^`]+)`.*/\1/')
>   if [ ! -f "$f" ]; then echo "MAT TEP: $l"
>   elif ! grep -qF -- "$s" "$f"; then echo "MAT CHUOI: $l"
>   else echo "khoi: ${l%%:Nguồn mẫu*} <- $f"; fi
> done <<< "$(grep -rnE '^Nguồn mẫu: `src/[^`]+`, chuỗi `[^`]+`' docs/quy-uoc docs/wiki-core/be/ly-do docs/wiki-core/fe/ly-do)"
> echo "da xet: $n dong nguon"
> ```
>
> **PASS: không dòng `MAT TEP`, `MAT CHUOI`.** Mỗi dòng `khoi:` là một khối kèm tệp nó trích — người soát mở hai bên ra so khi phần đổi chạm tệp đó. `da xet: 0` nghĩa là chưa khối nào mang dòng nguồn: lệnh không kiểm gì, không phải PASS. Lệnh không kiểm dòng kế tiếp có phải rào mở khối hay không, và không thấy khối chép mà thiếu dòng nguồn.
